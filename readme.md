1. to use this you need to get ffmpeg from here https://www.gyan.dev/ffmpeg/builds/
2. then you have to install the extension into chrome (search guides or ask ai)
3. run the server and select the folder where your ffmpeg.exe lies
the server can be the downloader.py from the server folder in this project OR you can get it from releases the whole .exe file (doesn't require dependencies like python flask and others)
if you are gonna use downloader.py you should do pip install flask flask-cors yt-dlp pystray pillow pywin32
4. in the extension you can choose mp4 or mp3 or the quality of the file and then click download
5. wait for a bit (dont close the server but you can hide it into the system tray by right clicking a red icon in the tray and pressing hide button) and the file should appear in ur downloads folder on c: disk
